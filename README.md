# 🏠 Rentease

**Rentease** is a full-stack rental management platform designed to make it easier for landlords and property managers to manage tenants, properties, rent payments, and rental operations from one place.

## 🚀 Features

* 🔐 User authentication
* 🏠 Property management
* 👤 Tenant management
* 💰 Rent tracking
* 📊 Dashboard and rental overview
* 🔒 Secure API architecture
* 📱 Responsive interface

## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone <your-repository-url>
cd Rentease
```

### 2. Install dependencies

```bash
# Frontend
cd client
npm install

# Backend
cd ../server
npm install
```

### 3. Configure environment variables

Create a `.env` file inside the server directory:

```env
PORT=5000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_jwt_secret
```

### 4. Start the application

```bash
# Backend
npm run dev

# Frontend
npm run dev
```
